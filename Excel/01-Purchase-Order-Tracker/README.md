# Procurement Purchase Order Tracker

## Overview

A beginner-level Excel project designed to practice fundamental spreadsheet skills in a procurement and supply chain context.

The project uses a fictional set of purchase orders to organize purchasing data, calculate purchase order costs, and perform basic analysis.

## Skills Demonstrated

- Data organization and formatting
- Excel formulas
- Basic arithmetic calculations
- SUM and AVERAGE functions
- COUNTIF function
- Sorting and filtering
- Currency formatting
- Basic procurement spend analysis
- Creating summary metrics

## Project Scenario

The workbook simulates a Purchasing Assistant tracking purchase orders from multiple suppliers.

The dataset includes:

- Purchase order numbers
- Suppliers
- Items purchased
- Quantities
- Unit prices
- Total purchase order costs
- Purchase order status

## Tools

- Microsoft Excel

## Project Level

Beginner

This project is the first project in my procurement analytics portfolio and serves as a foundation for more advanced Excel projects involving supplier analysis, spend analysis, and procurement dashboards.
