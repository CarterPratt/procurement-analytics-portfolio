# Supplier Spend Analysis

## Project Overview

This project uses Excel to analyze a fictional company's purchase order data and identify supplier spending patterns and potential supplier concentration risks.

The goal was to practice using Excel to perform basic procurement analysis and turn raw purchasing data into useful information for decision-making.

## Procurement Questions

* How much does the company spend with each supplier?
* How many purchase orders does each supplier have?
* What percentage of total spending goes to each supplier?
* Which suppliers represent the greatest concentration of company spending?
* How can purchase order information be quickly retrieved?

## Excel Skills Demonstrated

* Excel Tables
* `SUMIF`
* `COUNTIF`
* `IF`
* `XLOOKUP`
* Absolute cell references
* Percentage calculations
* Data validation/dropdown lists
* Conditional formatting
* Currency and percentage formatting
* Charts and data visualization

## Analysis Performed

### Supplier Spend Analysis

Calculated total spending for each supplier using `SUMIF`.

### Category Spend Analysis

Calculated total spending across purchasing categories.

### Purchase Order Counts

Used `COUNTIF` to determine how many purchase orders were associated with each supplier.

### Supplier Concentration

Calculated each supplier's percentage of total company spending and classified concentration risk.

### Purchase Order Lookup Tool

Created an interactive dropdown using data validation. Users can select a purchase order and automatically retrieve its:

* Supplier
* Item
* Total Spend

using `XLOOKUP`.

## Key Finding

Evergreen Industrial represented the largest share of total supplier spending at approximately 30%, making it the supplier with the highest concentration classification in this analysis.

However, spending was relatively distributed across the four suppliers, with no single supplier representing a majority of total spending.
