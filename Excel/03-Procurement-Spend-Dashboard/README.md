# Procurement Spend Dashboard

## Overview

This project is an Excel-based procurement dashboard designed to provide a clear overview of purchasing activity, supplier spending, and procurement performance.

The dashboard summarizes purchase order data and presents key metrics and visualizations that can help procurement teams monitor spending and identify trends.

## Key Metrics

- Total Spend: $36,130.00
- Total Purchase Orders: 30
- Average PO Value: $1,204.33
- Pending Purchase Orders: 2
- Average Delivery Days: 6.5

## Dashboard Features

- KPI summary of procurement activity
- Spend by supplier
- Spend by category
- Monthly spend trends
- Pending purchase order tracking
- Average delivery time analysis

## Excel Skills Demonstrated

- Excel Tables
- SUM and AVERAGE formulas
- COUNTIF and COUNTA
- PivotTables
- PivotCharts
- Data organization and formatting
- Procurement spend analysis
- Dashboard design and visualization

## Tools

- Microsoft Excel

## Purpose

This project demonstrates practical Excel skills that can be applied to procurement, purchasing, supply chain, and operations roles.
